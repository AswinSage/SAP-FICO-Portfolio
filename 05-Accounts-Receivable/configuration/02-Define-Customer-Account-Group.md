# Define Customer Account Group

## 1. Objective
Define a Customer Account Group to control customer master classification, number assignment, and field status.

## 2. Business Purpose
The source describes the account group as determining customer number ranges and controlling which customer master fields are required, optional, suppressed, or display-only.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Financial Accounting → Accounts Receivable and Accounts Payable → Customer Accounts → Master Data → Preparations for Creating Customer Master Data → Define Account Groups with Screen Layout (Customers)`

## 4. Procedure
1. Select New Entries.
2. Enter the Customer Account Group.
3. Enter the Description.
4. Assign the Number Range.
5. Maintain the required Field Status settings.
6. Verify mandatory details.
7. Save.
