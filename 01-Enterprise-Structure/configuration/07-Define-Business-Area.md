# Define Business Area

## 1. Objective
Define a Business Area used to classify financial transactions across distinct business activities or responsibilities.

## 2. Business Purpose
The source describes Business Areas as supporting reporting and analysis of revenues, expenses, assets, and liabilities for different business operations.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Enterprise Structure → Definition → Financial Accounting → Define Business Area`

## 4. Procedure
1. Select New Entries.
2. Enter the four-digit Business Area.
3. Enter the Description.
4. Verify the entered details.
5. Save.

## 5. Project Values
| Field | Project value |
|---|---|
| Business Area | Record from SAP |
| Description | Record from SAP |

## 6. Validation
- [ ] Business Area exists.
- [ ] Identifier and description match the project design.
- [ ] Saved entry can be displayed.
