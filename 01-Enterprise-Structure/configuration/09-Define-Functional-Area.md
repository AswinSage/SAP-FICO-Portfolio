# Define Functional Area

## 1. Objective
Define a Functional Area used to classify expenses and revenues according to business function.

## 2. Business Purpose
The source describes Functional Areas as supporting functional financial reporting and analysis of costs incurred by functions such as Production, Administration, Sales, or Research and Development.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Financial Accounting → Financial Accounting Global Settings → Functional Areas → Define Functional Area`

## 4. Procedure
1. Select New Entries.
2. Enter the four-digit Functional Area.
3. Enter the Description.
4. Select the Functional Area Type, if required.
5. Verify mandatory details.
6. Save.

## 5. Project Values
| Field | Project value |
|---|---|
| Functional Area | Record from SAP |
| Description | Record from SAP |
| Functional Area Type | Record if required |

## 6. Validation
- [ ] Functional Area exists.
- [ ] Description is correct.
- [ ] Functional Area Type is checked where applicable.
