# Define Consolidation Business Area

## 1. Objective
Define a Consolidation Business Area used to group multiple Business Areas for consolidated financial reporting.

## 2. Business Purpose
The source describes this unit as providing a common reporting structure for combining financial information from related business areas.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Enterprise Structure → Definition → Financial Accounting → Define Consolidation Business Area`

## 4. Procedure
1. Select New Entries.
2. Enter the four-digit Consolidation Business Area.
3. Enter the Description.
4. Verify the entered details.
5. Save.

## 5. Project Values
| Field | Project value |
|---|---|
| Consolidation Business Area | Record from SAP |
| Description | Record from SAP |

## 6. Validation
- [ ] Consolidation Business Area exists.
- [ ] Identifier and description are correct.
- [ ] Entry can be displayed after saving.
