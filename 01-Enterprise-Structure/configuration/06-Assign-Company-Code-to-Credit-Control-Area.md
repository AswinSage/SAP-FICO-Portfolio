# Assign Company Code to Credit Control Area

## 1. Objective
Document assignment of a company code to a Credit Control Area.

## 2. Business Purpose
The source explains that this assignment enables the Credit Control Area to monitor customer credit limits and outstanding exposure for the assigned company code.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Enterprise Structure → Assignment → Financial Accounting → Assign Company Code to Credit Control Area`

## 4. Procedure
1. Select the Company Code.
2. Enter the Credit Control Area.
3. Verify the assignment.
4. Save.

## 5. Assignment Record
| Field | Project value |
|---|---|
| Company Code | Record from SAP |
| Credit Control Area | Record from SAP |
| Assignment result | Pending verification |

## 6. Validation
- [ ] Company code exists.
- [ ] Credit Control Area exists.
- [ ] Correct assignment is saved and can be displayed.
