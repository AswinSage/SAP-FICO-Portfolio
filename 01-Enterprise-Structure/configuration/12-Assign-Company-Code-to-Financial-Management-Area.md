# Assign Company Code to Financial Management Area

## 1. Objective
Document the assignment of a company code to a Financial Management Area.

## 2. Business Purpose
The source explains that this assignment supports budgeting and fund control for the company code within the Financial Management Area.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Enterprise Structure → Assignment → Financial Accounting → Assign Company Code to Financial Management Area`

## 4. Procedure
1. Select the required Company Code.
2. Enter the Financial Management Area.
3. Verify the assignment.
4. Save.

## 5. Assignment Record
| Field | Project value |
|---|---|
| Company Code | Record from SAP |
| Financial Management Area | Record from SAP |
| Assignment result | Pending verification |

## 6. Validation
- [ ] Company Code exists.
- [ ] Financial Management Area exists.
- [ ] Correct assignment is saved and can be displayed.
