# Define Vendor Account Group

## 1. Objective
Define a Vendor Account Group to control vendor master classification, number assignment, and screen layout.

## 2. Business Purpose
The source describes the account group as controlling vendor master creation, number range assignment, and field status behavior (required, optional, suppressed, or display-only).

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Financial Accounting → Accounts Receivable and Accounts Payable → Vendor Accounts → Master Data → Preparations for Creating Vendor Master Data → Define Account Groups with Screen Layout (Vendors)`

## 4. Procedure
1. Select New Entries.
2. Enter the Vendor Account Group.
3. Enter the Description.
4. Assign the Number Range.
5. Maintain the Field Status settings.
6. Verify mandatory details.
7. Save.
