# Process 13: Vendor Line-item Report – BE Solution Pvt Ltd

## 1. Objective

Document review of all transactions posted to the selected vendor account.

## 2. Business Purpose

The source describes the Vendor Line-item Report as displaying invoices, payments, credit memos, clearing documents, and outstanding balances. It supports monitoring vendor liabilities and payment history.

## 3. Process Flow

- Preceding process: Vendor Posting
- Required process: Vendor Line-item Report
- Succeeding process: Nil

## 4. Prerequisites

- Configuration required: Nil, according to the source.
- Master data required: Vendor Master (`XK01`).
- Report stated in source: `FBL1N`.

## 5. Procedure Outline

1. Open the Vendor Line-item Report.
2. Enter the vendor account and company code.
3. Set the relevant date range and open/cleared item selection.
4. Execute the report.
5. Review the rent invoice, partial payment, residual payment, and outstanding items where applicable.
6. Capture the report output.

## 6. Validation

- [ ] Correct vendor and company code are selected.
- [ ] Invoice and payment entries are displayed.
- [ ] Clearing status and open balances are reviewed.
- [ ] Report agrees with the related posting documents.
