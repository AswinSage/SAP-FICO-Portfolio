# Process 8: G/L Line-item Report – Cash and Rent G/L Accounts

## 1. Objective

Document retrieval of G/L line items for Cash and Rent accounts.

## 2. Business Purpose

The source describes the G/L Line-item Report as a report used to display transactions posted to a specific G/L account, including debit and credit entries, document numbers, posting dates, and account balances. It supports reconciliation, audit, and financial analysis.

## 3. Process Flow

- Preceding process: G/L Posting
- Required process: G/L Line-item Report
- Succeeding process: Nil

## 4. Prerequisites

- Configuration required: None.
- Master data required: G/L Master Data.
- Report stated in source: `FBL3N`.

## 5. Procedure Outline

1. Open the G/L Line-item Report using the transaction stated in the source.
2. Enter the relevant company code and G/L account selection.
3. Enter the reporting date or period and other required selection criteria.
4. Execute the report.
5. Review the Cash and Rent account line items.
6. Save or capture the output for project evidence.

## 6. Validation

- [ ] Correct company code and G/L accounts are selected.
- [ ] Relevant posting dates and document numbers are displayed.
- [ ] Debit and credit values are reviewed.
- [ ] Report output agrees with the related posting documents.
