# General Ledger Configuration Overview

## 1. Objective

Organize the General Ledger configuration activities identified in the SAP FICO implementation project.

## 2. Configuration Sequence

| No. | Activity | Key output |
|---:|---|---|
| 1 | Define Chart of Accounts | Chart of Accounts definition |
| 2 | Assign Company Code to Chart of Accounts | Company code assignment |
| 3 | Define Account Group | Account group and account number range |
| 4 | Define Retained Earnings Account | P&L statement account type assignment |
| 5 | Create G/L Master Data | G/L account master record |
