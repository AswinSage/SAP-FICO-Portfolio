# Assign Company Code to Chart of Depreciation

## 1. Objective
Document assignment of the Chart of Depreciation to the relevant company code.

## 2. Business Purpose
The source explains that this assignment establishes the depreciation areas and valuation rules applicable to assets within the company code. Each company code is assigned to one Chart of Depreciation.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Financial Accounting → Asset Accounting → Organizational Structures → Assign Chart of Depreciation to Company Code`

## 4. Procedure
1. Select the required Company Code.
2. Enter the Chart of Depreciation.
3. Verify the assignment.
4. Save.

## 5. Assignment Record
| Field | Project value |
|---|---|
| Company Code | Record from SAP |
| Chart of Depreciation | Record from SAP |
| Assignment result | Pending verification |

## 6. Validation
- [ ] Company code exists.
- [ ] Chart of Depreciation exists.
- [ ] Correct chart is assigned.
- [ ] Assignment can be displayed after saving.
