# Define Asset Number Range

## 1. Objective
Document the number interval used when asset master records are created.

## 2. Business Purpose
The source explains that asset number ranges support internal or external numbering and are assigned to asset classes to provide systematic asset identification.

## 3. Configuration Activity
**SAP navigation:** `SPRO → IMG → Financial Accounting → Asset Accounting → Organizational Structure → Asset Class → Number Range`

## 4. Procedure
1. Enter the Company Code.
2. Enter the Number Range.
3. Enter the From Number.
4. Enter the To Number.
5. Verify the interval and save.

## 5. Project Values
| Field | Project value |
|---|---|
| Company Code | Record from SAP |
| Number Range | Record from SAP |
| From Number | Record from SAP |
| To Number | Record from SAP |
| Internal / External | Record actual setting if displayed |

## 6. Validation
- [ ] Company code is correct.
- [ ] Number range interval is maintained.
- [ ] From and To values are checked.
- [ ] Assignment to the relevant asset class is verified.
