# Define Asset Screen Layout

## 1. Objective
Document the screen layout rules controlling fields displayed during asset master creation and maintenance.

## 2. Business Purpose
The source explains that screen layout rules determine whether asset master fields are required, optional, suppressed, or display-only. The screen layout is assigned to an asset class.

## 3. Configuration Activity
**SAP navigation:** `SPRO → IMG → Financial Accounting → Asset Accounting → Organizational Structure → Asset Class → Screen Layout Rules`

## 4. Procedure
1. Select the required screen layout.
2. Copy the layout.
3. Change the Screen Layout Code and Description.
4. Verify the copied layout.
5. Save.
