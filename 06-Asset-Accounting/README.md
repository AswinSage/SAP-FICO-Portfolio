# Asset Accounting (FI-AA)

## 1. Overview
Asset Accounting manages fixed-asset master records and the accounting values associated with acquisition, depreciation, transfer, and retirement. The implementation project covers chart of depreciation, depreciation areas, asset classes, depreciation keys, account determination, and G/L integration.

## 2. Configuration Scope
- Chart of Depreciation
- Depreciation Areas
- Account Determination Key
- Asset Classes
- Depreciation Keys
- G/L Account Determination

## 3. Business Process Scope
The companion Business Processes document covers single asset master creation, group asset master creation, and sub-asset creation.

## 4. Documentation Structure
- `configuration/`: Asset accounting setup
- `master-data/`: Asset master records
- `business-processes/`: Source Processes 20–22
- `testing/`: Asset test cases and evidence
- `screenshots/`: Redacted SAP evidence

## 5. Validation
Check asset class, asset number, depreciation terms, account determination, asset values, and report outputs. Asset master creation is distinct from acquisition posting and depreciation execution.
