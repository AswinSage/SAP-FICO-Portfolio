# Global Settings Configuration Overview

## 1. Objective

Document the Global Settings configuration activities identified in Phase 2 of the SAP FICO implementation project.

## 2. Configuration Sequence

| No. | Configuration activity | Assignment / follow-up |
|---:|---|---|
| 1 | Define Field Status Variant | Create field status groups and maintain field controls |
| 2 | Assign Company Code to Field Status Variant | Assign the required variant to the company code |
| 3 | Maintain Fiscal Year Variant | Define posting periods and special periods |
| 4 | Assign Fiscal Year Variant to Company Code | Assign the required fiscal year variant |
| 5 | Define Posting Period Variant | Define the posting period control variant |
| 6 | Define Tolerance Groups for Employees | Maintain document, open-item and payment-difference limits |
| 7 | Assign User Name to Tolerance Group | Assign the user to the applicable tolerance group |
