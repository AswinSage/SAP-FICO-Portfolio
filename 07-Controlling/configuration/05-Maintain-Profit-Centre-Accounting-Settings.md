# Maintain Profit Centre Accounting Settings

## 1. Objective
Document Profit Centre Accounting settings maintained for the Controlling Area.

## 2. Business Purpose
The source describes Profit Centre Accounting as collecting revenues and costs by Profit Centre to determine operating results and compare performance across organizational areas.

## 3. Configuration Activity
**SAP navigation:** `SPRO → SAP Reference IMG → Controlling → Profit Center Accounting → Basic Settings → Controlling Area Settings`

## 4. Procedure
1. Enter the Controlling Area.
2. Select the required Profit Centre Accounting settings.
3. Maintain the Currency Type.
4. Maintain the Fiscal Year Variant.
5. Select the required Ledger, if applicable.
6. Verify mandatory settings.
7. Save.

## 5. Project Values
| Field | Project value |
|---|---|
| Controlling Area | Record from SAP |
| Profit Centre Accounting settings | Record from SAP |
| Currency Type | Record from SAP |
| Fiscal Year Variant | Record from SAP |
| Ledger | Record if applicable |

## 6. Validation
- [ ] Controlling Area is correct.
- [ ] Profit Centre Accounting settings are maintained.
- [ ] Currency and fiscal year settings are checked.
- [ ] Ledger selection is documented if applicable.
