# Controlling Configuration Overview

## 1. Objective
Organize the Controlling configuration activities identified in Phase 7 of the implementation project.

## 2. Configuration Scope
The implementation report identifies the Controlling Area, Profit Centres, Cost Centres, Cost Elements, and Internal Orders as key project configuration areas.

| No. | Activity | Evidence required |
|---:|---|---|
| 1 | Maintain Controlling Area | Controlling Area and company code assignment |
| 2 | Maintain Profit Centre structure | Profit Centre and hierarchy evidence |
| 3 | Maintain Cost Centre structure | Cost Centre and hierarchy evidence |
| 4 | Maintain Cost Elements | Primary/secondary cost element evidence |
| 5 | Maintain Internal Orders | Order type and number range evidence |
