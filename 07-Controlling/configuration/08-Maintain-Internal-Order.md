# Maintain Internal Order

## 1. Objective
Document Internal Order master creation for planning, collecting, monitoring, and settling costs for specific activities or events.

## 2. Business Purpose
The source describes Internal Orders as cost objects for temporary projects, events, maintenance activities, and other specific purposes.

## 3. Master Data Activity
**SAP navigation:** `SAP Easy Access → Accounting → Controlling → Internal Orders → Master Data → Order → Create`

## 4. Procedure
1. Enter the Controlling Area.
2. Enter the Order Type.
3. Press Enter.
4. Enter the Internal Order Description.
5. Enter the Person Responsible.
6. Enter the Company Code.
7. Enter the Business Area, if required.
8. Enter the Profit Centre, if required.
9. Maintain the Settlement Rule, if required.
10. Verify mandatory details.
11. Save.

## 6. Validation
- [ ] Internal Order is created.
- [ ] Order type and Controlling Area are correct.
- [ ] Company code and optional assignments are checked.
- [ ] Settlement rule is checked if maintained.
